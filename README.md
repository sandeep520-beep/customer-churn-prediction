\# Customer Churn Prediction and Retention Analytics



\## Project Overview

A Machine Learning project that predicts whether a telecom customer is likely to leave a company using customer demographics, service details, tenure, and billing information.



\## Objectives

\- Perform Exploratory Data Analysis (EDA).

\- Identify customer churn patterns.

\- Train Logistic Regression and Random Forest models.

\- Evaluate models using Accuracy, Precision, Recall, F1-score, and ROC-AUC.

\- Support customer retention decisions.



\## Technologies

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn

\- Joblib

\- Streamlit



\## Dataset

Telco Customer Churn dataset containing 7,043 customer records and 21 columns.



\## EDA

\- Customer Churn Distribution

\- Customer Tenure vs Churn

\- Monthly Charges vs Churn



\## Initial Model Results



| Metric | Logistic Regression | Random Forest |

|---|---:|---:|

| Accuracy | 80.38% | 78.18% |

| Precision | 64.85% | 61.59% |

| Recall | 57.22% | 47.59% |

| F1-score | 60.80% | 53.70% |

| ROC-AUC | 83.59% | 81.11% |



Logistic Regression achieved the better initial F1-score.



\## Key Findings

\- Customers with shorter tenure showed a higher tendency to churn.

\- Customers who churned generally had higher monthly charges.

\- Logistic Regression performed better than Random Forest in the initial comparison.
